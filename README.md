# Leeh Costura Premium

Sistema web para gestão de produção de costura de sofás.

## Objetivo

Automatizar o controle da produção e substituir processos feitos manualmente em caderno.

O sistema permite:

- Controle de funcionários
- Controle de fábricas
- Controle de cargas
- Controle de serviços
- Controle de produção
- Fechamento de pagamentos
- Relatórios administrativos

- Laravel 13
- PHP 8.4
- SQLite
- Blade
- CSS
- Herd

---

## Como executar

Instalar dependências:

composer install

Executar migrations:

php artisan migrate

Iniciar projeto:

php artisan serve
